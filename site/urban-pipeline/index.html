How a Workday export became reviewed author bios

Urban Pipeline is a Drupal module I built at the Urban Institute. It compared the HR system's employee export with the author bios on urban.org, queued every difference for a person to approve, and saved approved changes as drafts for editors to publish. It needs Urban's site and a real Workday file to run, so this is a re-enactment drawn from its code, with made-up people.
