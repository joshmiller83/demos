Demos

Working front-end pieces from past projects, isolated so you can use them in the browser.

  • Mini catalog: CSV in, catalog out

    Point a web component at a CSV and get a catalog you can search, filter and page through. Five presets show its modes, and you can edit a CSV or load your own and watch it render.

  • Search results component

    Faceted, paginated search results from a Drupal Search API index, here running against a mock of the JSON:API endpoint.

  • Upward Mobility data dashboard (write-up)

    How a Drupal module fed a public data dashboard: a cached JSON API, editor forms that controlled its wording, order and chart behavior, and React web components that read both. Links to the live dashboard.

  • Wild Birds Unlimited MCP (concept)

    An animated pitch for an MCP server that answers AI assistants from a bird store chain's own systems: live hours, shelf counts, events and staff sightings. Twelve tools play out as chats with customers across the US and Canada, from the question to a hold, RSVP or booking. Sample data, not affiliated with Wild Birds Unlimited.

  • Urban Pipeline, played out

    A three-minute animated re-enactment of a Drupal module I built at the Urban Institute. It matched a Workday employee export to author bios, queued each difference for review in a bulk-operations view, and saved approved changes as drafts for editors to publish.
